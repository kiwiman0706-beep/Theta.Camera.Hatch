Wi-Fi
[ ] 初回権限許可→AP承認→API応答→ライブ表示。必要操作数と秒数を計測。
[ ] 2回目接続を10回。AP具体的指定で追加の選択が必要か記録。
[ ] アプリ再起動、端末再起動、ネットワーク忘却、権限取り消し後。
[ ] カメラOFF/無線OFF/圏外/パスワード変更/スマホWi-Fi OFF。
[ ] 通常Wi-Fi接続中、モバイル回線のみ、機内モード+Wi-Fi、VPNあり。
[ ] 二重Wi-Fi対応/非対応スマホでインターネット通信への影響を確認。
[ ] Sのv2.0→v2.1初期化が再接続後も通る。
[ ] 640x320/10fps、静止画撮影で停止→保存完了→再開。
[ ] タイムアウトした撮影を再送せず結果を照会できる。

USB
[ ] 権限許可/拒否、初回/再接続、データ非対応ケーブル、OTG機能OFF。
[ ] DeviceInfo/Supported一覧/FunctionalModeを取得。
[ ] PassphraseをGETし、変更済みパスワードでもWi-Fi接続できる。ログには出ない。
[ ] 写真一覧、サムネイル、原本取得、単写、DeviceBusy。
[ ] 小容量/大容量/多数ファイル、保存先満杯、画面回転、バックグラウンド化。
[ ] 転送中抜き差し/アプリ終了/本体停止で破損原本を完成扱いしない。
[ ] 再接続時のObjectHandle再同定、部分再開または安全な再取得。

経路切替
[ ] USB接続中に本体Wi-Fiが使えるか。接続順序を両方試す。
[ ] USB転送中にライブ要求→待機または安全停止→Wi-Fi接続。
[ ] Wi-Fi撮影した画像をUSBで取り込んでも重複扱いを誤らない。
[ ] 同名ファイル/別カメラ/カメラ初期化後の衝突を誤認しない。

USBライブ将来検証

[ ] 1280x720/15fps MJPEGの未加工映像。
[ ] CAMERA/USB権限拒否、再列挙、UVC→通常モード復帰。
[ ] 5分/30分の実fps、p50/p95遅延、ドロップ、温度、電池消費。
[ ] スティッチ前後の向き/境界/近接視差/上下。
[ ] 通常静止画撮影・MTP転送との併用可能性は実結果で記録。

性能比較の方法
同一の写真集合をWi-Fi/USBで各3回以上転送。総バイト数、総時間、実効MB/s、失敗/再試行、ピークメモリを記録。
サムネイル取得・接続時間・原本転送時間を分ける。OSキャッシュ/画面状態/給電条件を揃える。
接続UXは初回と再接続を分け、ユーザータップ数、初フレームまでの時間、追加設定画面回数を記録。

意味のある自動確認
MJPEGの分割/結合read、異常長/EOF/キャンセル。
MTPコンテナの分割、応答transaction IDの不一致、DeviceBusy、USB切断。
接続中キャンセルと古いcallbackの無視、転送ファイルの確定条件、異経路重複判定。
自動確認合格はハードウェア互換性の証明ではない。
