所有カメラのAndroid連携 調査・Claude引き継ぎ
2026-11-14 / UTF-8

今回の対象
・GoPro HERO8 Black（ユーザー確認済み）
・Insta360 GO Ultra
・RICOH WG-5（製品名はWG-5 GPSとして調査）
・DJI Pocket 2（「2だったと思う」との回答に基づく。実装前に本体モデルを確認）
・Pocket 2のDo-It-Allハンドルまたはワイヤレスモジュールは所有しているとの回答。

結論
GO Ultra: 現行の公式Android SDK V2対応。最も有望な追加対象。SDKの申請/取得条件を満たし、GO Ultraの接続方式別対応を実機確認する。
HERO8: Open GoPro公式対応外。ただし非公式のBLE/Wi-Fi制御とファイル取得資料が具体的。USBはMTPファイル取得とGoPro Connect映像を別扱い。
WG-5 GPS: USB MSC/PTPやSDカードによる画像取り込みが候補。THETA同等の公開撮影・ライブAPIは確認できない。
Pocket 2: 公式Mimoでは無線操作可能だが、Pocket 2向け公開SDKを確認できない。カード取り込みを基準にし、非公式Wi-Fi連携は研究枠。

最初に01_Claudeへの引き継ぎ.txtを読ませる。02〜05が機種別、06が共通設計、07が実機検証。
references/には固定コミットで取得した公開資料を収録。メーカーSDKバイナリ、ログイン情報、ファームウェアは含まない。
previous/には前回のTHETA S資料ZIPをそのまま添付。THETA資料は2026-11-13版であり、今回の4機種向けプロトコルではない。

「ライブ」の区別
1. 構図確認用のリアルタイムプレビュー
2. カメラ本体での高品質写真/動画記録
3. RTMPなどへの配信
4. PC/スマホが普通のWebカメラとして認識するUVC等
1〜4のどれかが可能でも残りが可能とは限らない。録画中プレビュー、USB中撮影、転送中撮影も別の能力。

確認レベル
公式仕様で確認 / 非公式作者が報告 / 設計提案 / 未確認を区別して記載。
今回カメラの実機テスト・SDKビルド・既存アプリ改修は実施していない。
