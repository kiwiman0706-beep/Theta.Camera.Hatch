# 動く操作モック

`index.html` を展開後ブラウザで開く。編集用の元断片は `source/theta-camera-fold-editor.html`。`history/` は以前の案で、最新版ではない。

## 試す順番

1. 「操作を表示」でオーバーレイを出す。開閉ボタンで内外画面の変化を見る。
2. 外画面ライブと外画面シャッターを切替。開いた状態の映像のみ／撮影可能を比べる。
3. 4分割の各枠で録画・写真、ダブルタップ拡大。録画中に「章＋」と写真を操作。
4. 下の写真を押して同じ面へ表示。ペン／マウスで書き、文字や音声メモを追加。版の束を上へ展開。
5. 下のフォルダを長押しして今後の保存先を変更。既存写真の振り分け、イベント・タグ・☆・コメントと一覧の抽出を試す。
6. 動画サムネイル→「カット＋結合・コマ送り」。シーク、前後1コマ、ジョグ、分割・削除・取消、動画追加、「このコマを保存」。

カメラ、動画、音声、スキャン、声シャッターは操作デモ。状態はメモリ内で、再読込みでリセットする。実ファイル保存、機密保管、NAS送信は行わない。LIVEも仮想表示。最新の人物登録はFACE_TAGGING.mdに記載し、このモックにはまだ追加していない。

表示用ライブラリに外部CDNを使う場合があるため、初回表示はインターネット接続のあるブラウザを推奨。画面検証状況はPACKAGING_VALIDATION.mdを参照。

状態遷移の検証（Node.js）：

```sh
node mock/tests/verify-state.cjs
```

簡易DOMでのロジック確認であり、実ブラウザ描画やAndroidカメラ動作の検証ではない。
