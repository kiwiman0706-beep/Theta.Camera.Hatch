## 最初に試す

1. 同梱の署名済みAPKをインストールし、カメラを許可する。
2. 閉じた状態で起動し、写真を1枚撮影。ギャラリーの `DCIM/ThetaCamera` を確認。
3. 閉じた状態から本体をほぼ全開にする。自動的に外側画面への切替を要求する。
4. OSの確認が表示されたら承認。外側画面にプレビューが移れば、アウトカメラで自撮り可能。
5. 自動切替しないときは画面上の大きな「外側画面で自撮り」ボタンを使う。
6. 「診断」→「コピー」で、機種・公開レンズ・解像度・HDR等の対応状況を共有できる。

写真撮影・動画録画とも実機テストが必要です。Fold5そのもののカメラ・OSをこの開発環境から操作して検証したものではありません。ビルドと自動検査の結果は `VALIDATION.md` を参照してください。

## 実装した機能

- CameraX 1.6.2による写真・動画プレビューと保存。
- 公開Camera ID一覧からレンズ選択、前面／背面切替。
- ピンチズーム、倍率ボタン、ズームスライダー。倍率は選択中カメラに対する倍率。0.6倍ボタンは超広角の利用を保証しない。別IDで公開される超広角はレンズ一覧で選択。
- タップAF/AE、露出補正、フラッシュ／連続ライト。
- 4:3 / 16:9、通常／最大公開解像度、JPEG高品質。
- CameraX拡張によるメーカー自動・HDR・夜景・ポートレート・美肌。使用中のカメラで公開されるモードのみ表示。
- 対応構成でUltra HDR JPEGまたはRAW+JPEG（DNGとJPEGの2ファイル）。RAW+JPEG選択時は標準撮影モード。
- 動画の公開対応画質選択（4K/1080p/720p等）、対応時HLG 10-bit HDR、60fps要求、対応時動画手ぶれ補正。
- マイクは録画時に必要になってから要求。拒否しても無音で撮影できる。
- 標準モードで対応時ISO・シャッター速度、手動フォーカス、WBプリセット。
- 3/5/10秒セルフタイマー、音量キーシャッター、グリッド、簡易水平ガイド、直前の撮影結果表示。
- 縦持ち／横持ちで操作部を配置変更。操作の多い行は横スクロール。
- 閉じた→155°以上に開いた動きを検知し、Rear Displayへの切替を自動要求。
- 自動切替ON/OFFと大きな手動切替ボタン。キャンセル後の同じ開閉動作で再要求しない。
- 動画録画中・写真保存中・タイマー中は自動切替を保留する。
- Hinge Angleセンサー優先、センサーがない場合はWindowLayoutInfoで推定。
- 端末機能診断とコピー／Android共有。
- 写真・動画はMediaStoreでDCIM/ThetaCameraへ保存。既存写真を読む権限、位置情報権限、インターネット権限は要求しない。
- 自動切替、解像度設定、グリッド、タイマー、録音設定、直前の撮影結果を保持。

## 制限・重要な仕様

- 自作アプリ内での撮影が対象。Samsung純正カメラのUIや動作を変更するアプリではない。
- Rear DisplayはOne UI / Android / 端末実装に依存。OS確認ダイアログをアプリから消すことはできない。毎回の確認の有無と移行の滑らかさは実機検証対象。
- 閉じる際のRear Displayセッション終了はOSの通知に従う。録画中に物理的な画面移行が起きた場合、OSのライフサイクルにより録画が終了する可能性がある。
- 動画はバックグラウンド録画をしない。アプリが非表示になれば停止する。
- 50MPセンサーでも50MPが外部アプリに公開されるとは限らない。画面にCameraXで実際に採用された写真解像度を表示。
- HDR写真のメーカー拡張、Ultra HDR JPEG、HLG HDR動画は別機能。端末やレンズごとに対応が異なる。
- 拡張／RAW／高解像度／HDR／高FPS等の組合せが非対応なら、通知して標準へ戻す。60fpsは要求値であり実測値ではない。
- センサーがない場合の開閉推定は分割画面などで誤判定する可能性がある。Fold5は実機のセンサー報告を診断で確認。
- RAW+JPEG保存で片方だけ失敗した場合はエラーを表示する。成功した側のファイルが残る場合がある。
- グリッドはプレビュー領域全体の補助線で、レターボックスがある場合の保存画像の厳密な三分割線ではない。
- Samsung独自のシーン最適化・Expert RAWの合成・モーションフォト・超解像ズームと同じ処理は実装していない。
- 連写、8K、スローモーション、パノラマ、被写体追尾、デュアルプレビュー、カスタムボタン編集UIは今後の候補。
- 専用端末での検証前なので、重要な撮影では純正との撮り比べから始める。

## ビルド

Android Studioでこのフォルダを開く。JDK 17以上、Android SDK Platform 36 / Build Tools 36.0.0、インターネット接続が必要。

```sh
./gradlew assembleRelease testDebugUnitTest lintDebug
```

Windowsは `gradlew.bat` を使用。`local.properties` は自分のSDKパスでAndroid Studioが作成。

- applicationId: `com.theta.camera.hatch`
- minSdk 29 / targetSdk 35 / compileSdk 36
- AGP 8.13.0 / Kotlin 2.2.20 / Gradle 8.13
- CameraX 1.6.2 / WindowManager 1.4.0

## 署名の引継ぎ

このZIPの `signing/` に今回のAPK専用の署名鍵と設定を同梱。同じ鍵を使い、versionCodeを増やせば上書き更新できる。紛失しないよう保管する。
`signing/` は `.gitignore` で除外。公開リポジトリに鍵やパスワードをアップロードしない。
署名ファイルを共有しないソースだけでビルドする場合は、Android Studioで自分の署名構成を作成する。
